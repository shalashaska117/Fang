# Fang contributors

Fang is an independent project created and owned by Pietro Pellegrino.

Vampire's original authors and acknowledgements are preserved separately in
`LICENSES/Vampire.AUTHORS` and `LICENSES/Vampire.THANKS`. These lists credit work
on Vampire; they are not a list of Fang's authors or contributors.

New contributions must name their copyright holders and years. Adapted code
must retain inherited notices. `LICENSES/Vampire.ORIGIN` records the reference
commit and source files consulted.
